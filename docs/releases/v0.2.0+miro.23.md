# Skyward 0.2.0+miro.23 - USB drive notifications

- Show localized notifications when a drive becomes available, cannot be read,
  or is removed. Wake the screen so the message can be seen.
- Notify only on status changes; repeated polling does not repeat or extend
  a message. Preserve file-manager and backup navigation effects on removal.
- Retain r22's direct USB manager, default read-only mounts, and r21's OTG fix.

No filesystem repairs, writable USB mounts, ROM installation, AVB changes or
data erasure are introduced. Connection is reported after mounting succeeds;
an unreadable drive gets a distinct notification rather than a success claim.

Pre-update device log: data decrypted and no recovery restart was recorded.
One USB attempt encountered I/O errors and disconnected; reinsertion mounted
exFAT successfully. The volume reported an unclean prior unmount. No repair
or modification of USB files was performed.
