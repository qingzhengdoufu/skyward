# Skyward 0.2.0+miro.21 - OTG role-switch restart fix

- Treat an absent USB gadget controller as no connected computer. Switching
  the dual-role USB port to OTG host mode removes its UDC state node; r20
  propagated that normal disappearance as a fatal error and restarted the UI.
- Handle ENOENT, ENODEV and ENXIO for the gadget status read without suppressing
  unrelated errors. Add tests for controller removal and return.
- Expose the existing saved recovery-preservation switch on System Update.
  When enabled, the installer holds the current flashed Skyward image before
  OTA writes, restores it to the next slot and any other overwritten recovery
  selected by the existing policy, and reads it back. Default remains on.

No changes to encryption, credentials, touchscreen, AVB or USB filesystem
support. No claim that every USB drive mounts successfully. The reported
post-restart credential refusal needs testing after a clean recovery boot.
Real ROM installation, recovery preservation after OTA, and data erasure are
not exercised during device smoke testing. OTG insertion needs device retesting.
