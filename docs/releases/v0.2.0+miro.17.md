# Skyward 0.2.0+miro.17 - reviewed ZIP queue / full 7-Zip

Supersedes miro.16 before it was installed on the test phone. Retains the
script ZIP queue and full Android ARM64 7-Zip 26.06 described in the miro.16
notes, with these review fixes:

- Leaving the queue-add file picker clears its mode. A subsequent ordinary
  picker cannot silently enqueue a file instead of installing it.
- The picker itself also enforces the 10-entry limit.
- Failure to release MTP storage terminates the queue UI rather than leaving
  an apparent installation running with no worker.
- A merge or busy second-system worker also blocks queue startup.

Scope: no resizing, backup encryption, TWRP import or boot repacking added.
Existing destructive workflows remain experimental. Host queue tests do not
prove arbitrary third-party scripts safe. RAR decoding only, not RAR creation.
See resources/7zip for source, build flags and third-party licenses.

Tested: selected host tests/strict Clippy and independent image verification;
standalone 7-Zip encrypted 7z create/test/extract and wrong-password refusal
on the phone's /tmp. Real ROM queue installation is not part of validation.
Authorized device install targets recovery_a only; no AVB mutation or erase.
