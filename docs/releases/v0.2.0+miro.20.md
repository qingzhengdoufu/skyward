# Skyward 0.2.0+miro.20 - official China Mainland system updates

- Enable miro's built-in system update using Xiaomi's official OTA service.
  Query the latest China Mainland Stable full OTA dynamically; do not hardcode
  an OS version, scrape the catalog website, or use fastboot ROMs.
- Preserve resumable downloads and speed reporting; display percentage and a
  green download progress bar. Allow another update check when not downloading.
- Keep packages in /sdcard/downloaded_rom. Internal storage must be decrypted.
  An erased data partition must be initialized by the system before downloading.
- Add a default-off, one-shot "Format data after installation" option for the
  system update page's downloaded A/B OTA only. It is not persisted, inherited
  by ordinary ZIPs, images, queues or recovery self-updates, or applied on failure.
  Installation requires an explicit destructive slide confirmation beforehand.
- Reuse the existing guarded post-OTA factory-reset workflow after the installer
  releases its package. This erases data and metadata, including internal storage
  and the downloaded ROM. The installed system initializes encrypted data again.
- Shorten explanatory update text while keeping storage and erasure warnings.

Validation scope: host tests, UI previews, ARM64 build and read-only OTA query.
No real ROM installation or data erasure is part of device smoke testing.
Recovery installation targets the confirmed current recovery slot only.
