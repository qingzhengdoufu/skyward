# Skyward 0.2.0+miro.16 - ZIP queue and full 7-Zip

Unofficial REDMI K80 Pro (miro) adaptation, original project kirklin/skyward,
adaptation baseline Rinrroy/skyward-for-haotian d6e7b7a. GPL-3.0-or-later for
Skyward; the separate 7-Zip executable has its own bundled licenses.

## ZIP install queue

- Install -> ZIP install queue, add files from internal storage or USB, remove
  entries or move one upward. Maximum 10 unique script ZIPs. One slide starts
  the ordered list; selecting a ZIP in this picker does not install it.
- All entries must have update-binary and must identify as script packages.
  OTA payload ZIPs, second-system packages and .img files use single install.
- Preflight all paths; hash each ZIP before the first install and compare again
  before its turn. No persisted queue or automatic resume after reboot.
- Stop on failure/refusal/cancellation, recovery-preservation failure, a script
  asking for deferred cache wipe, or changed/unknown next boot slot before a
  subsequent ZIP. Per-package results and script log copies are retained.
- Scripts run as root and may write any partition, format data or reboot by
  themselves. Queue restrictions are not a sandbox. Inspect each ROM first.
  Changes by another process after the last check remain possible.
- Actual destructive multi-ROM installation is not tested or promised safe.

## Full 7-Zip

- Official 7-Zip 26.06 Alone2 (7zz), built from supplied unmodified official
  source for Android ARM64 API 30 using NDK r29, statically linked.
- 7za and 7z aliases invoke the full 7zz executable in this image. Includes
  create/list/test/extract, 7z/LZMA2/encrypted archives and supported upstream
  format handlers. RAR decoding is supported, RAR creation is not.
- Source archive, SHA-256, exact build flags, LGPL/BSD notices and unRAR
  restriction are included under resources/7zip. License files also travel in
  the ramdisk. This is a separate executable, not linked into the Rust binary.
- Standalone ARM64 binary tested on the phone in /tmp: encrypted 7z creation,
  testing, stdout extraction and wrong-password refusal. Host queue tests verify
  order, fail-stop, duplicate/type restrictions and UI confirmation.

Existing intro, decryption, touch compatibility and signed self-update remain.
No logical partition resizing, encrypted backup, TWRP import or boot repacking
has been added. No AVB mutation or actual ROM/partition write is part of testing.

The user authorized a separate recovery_a-only manual installation after
verification, followed by phone-storage image backup replacement. Tool tests
use /tmp synthetic files, never real system/data targets.
