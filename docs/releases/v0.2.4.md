# REDMI K80 Pro (miro) - first signed online-update release

Unofficial adaptation of kirklin/skyward, based on Rinrroy/skyward-for-haotian.
GPL-3.0-or-later. Build credits: 澪洛依 & 红烧豆腐.

## Changes

- Switch recovery self-update to wmin85099-cmd/skyward.
- Verify the release's P-256 signed image manifest and GitHub SHA-256 metadata.
- Download and validate first, then require a separate slide to confirm writing.
- Update only the currently booted slot's recovery partition, with read-back.
- Check unlocked bootloader, battery, OTA state, image size and miro config.
- Includes test11 touch compatibility, decryption, WLAN readiness retry, haptics,
  raw partition image export and experimental image-install tooling.

## Important

- K80 Pro / miro only. Stock recovery base OS3.0.303.0.WOMCNXM, Android 16.
- test11 password decryption, WLAN scan, USB charging and boot were observed.
  This 0.2.4 build and its on-device online-write path have not yet been tested.
- Old test11 does not know this repository: install 0.2.4 manually once to
  bootstrap this channel. Later releases can update over Wi-Fi.
- Self-update does not modify AVB, other slots, boot, super or user data.
  Existing recovery startup mount/settings behavior remains.
- True hardware panel-off touch resume and fast charging are not fixed.
- Real ROM flashing, automatic AVB writes and raw image export remain experimental.
- Do not relock the bootloader. Keep a verified rollback image and fastboot access.
- Signature verification pins this publisher's local key; it is not a Xiaomi
  signature, a verified-boot signature or a guarantee that an image has no bugs.
