# Skyward 0.2.0 + miro adaptation 13

This corrects the version naming, not an upstream feature merge.

- Upstream project kirklin/skyward is currently 0.2.0.
- Local package/display version is now 0.2.0+miro.13. The independent adaptation
  revision orders updates, because SemVer ignores build metadata by default.
- Source retains the Rinrroy d6e7b7a adaptation baseline and our existing K80 Pro
  work. No haotian 0.2.5 AOD/doze changes are transplanted.
- Signed self-update, single current-slot recovery writing, download verification
  and explicit slide confirmation from our previous release are retained.
- Old 0.2.4 clients compare ordinary SemVer and cannot automatically recognize
  this naming correction as newer. Install this image manually once. Subsequent
  miro clients compare adaptation revisions, including across upstream changes.
- Old v0.2.4 Release remains available for rollback; no tags/assets overwritten.

K80 Pro / miro only; stock OS3.0.303 recovery base, tested system OS3.0.305.
No fast-charge fix or hardware panel-off touch fix. ROM flash/automatic AVB writes
and single-image export remain experimental. No automatic AVB change during
self-update. Do not relock the bootloader.
