## Changes

- Replace the active WPE/AERA browser with Aurora's HTML reader and external
  Chromium/CDP session. Old WPE source remains in history/workspace but is not
  linked into the recovery or included as a payload.
- Basic browsing, forms, cookies, history, bookmarks, tabs and downloads.
- Full mode keeps Chromium alive, forwards touch/scroll/zoom/text and receives
  bounded screencast frames. Fixes the reference's shell quoting, HTTP page-list
  reads, first-frame delivery, idle timeout and tab-state bugs.
- New-window links navigate in the current Chromium page. Main-frame navigation
  updates the address/history. Attachment downloads enter the recovery download
  list; authenticated/blob/POST-only downloads are not yet covered.
- Downloads run independently of page loading and use green progress bars.
  Files go to /data/media/0/Download/Skyward after data decryption. Files already
  present are not overwritten; temporary files are cleaned up on cancellation.
- Full browser rootfs is under /data/skyward-browser/chromium. Installation checks
  the pinned release checksum, rejects escaping/special archive entries and stages
  the new rootfs before replacing an existing one. Certificate verification stays
  enabled in the replacement launcher. Debugging listens on loopback only.
- Root module manager reads Magisk/KernelSU/APatch modules and changes only the
  standard disable/remove markers. Removal can be cancelled. No module scripts
  are executed and payload folders are not deleted by these controls.
- Dedicated partition-image picker and management entry reuse the existing image
  inspection and confirmation workflow. super remains explicitly shared.
- Remove the power-off entry from the home page; reboot menu still has power-off.
- Status-bar pull-down center with WiFi, haptics, MTP, supported double-tap wake,
  brightness, existing device status, install progress and downloads.
- On-screen keyboard haptics obey the existing vibration preference.
